# Onboarding Health Score

Professional Services app for scoring a customer at Early Churn, Activation, and Pre-Sticky.

Published the same way as the WMS migration report:

https://nurisabuncu-alt.github.io/Onboarding-Health-Score/

Scores stay in the browser. Use Export and Import to move a customer book between machines. The first visit loads three sample customers. Remove them before entering live accounts.
